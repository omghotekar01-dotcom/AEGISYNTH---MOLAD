# AEGISYNTH Sentinel — Metropolis / Monad Testnet

This repository imports the public [original AEGISYNTH fraud-defence research prototype](https://github.com/omghotekar01-dotcom/Mastercard-project---AEGISYNTH), preserving its original source, and extends it toward an owner-governed testnet MON payment vault.

The existing synthetic fraud compiler generates a human-review package; it does **not** authorize or automatically deploy payment rules. The new vault must enforce explicit owner/reviewer/operator constraints on chain. Do not transfer real assets, expose private keys, or claim production fraud protection.

Deployment is **not confirmed** until contract tests pass and MonadVision shows a verified testnet transaction receipt.
